Forthcoming
-----------
* First release: ``jarvis-mcp``, a Model Context Protocol server (stdio; protocol 2025-06-18, 2025-03-26 and 2024-11-05) for AI assistants. Read-only tools over the gateway (status, faults, runbooks, incidents, events, recoveries, plans, analytics), ``ask_agent``, and ``request_recovery`` with ``--allow-recovery``. Standard library only; tested with the official MCP client.
