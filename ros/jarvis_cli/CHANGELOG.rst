Changelog for package jarvis_cli
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Forthcoming
-----------
* First release: ``ros2 jarvis`` faults, rules, plans, recover, mode, executions, approve, reject, cancel, export, lint and backtest.
* ``ros2 jarvis maintenance``: put a component under maintenance (``30m``, ``2h``, ``1d``), list the windows, ``--end`` one.
* ``ros2 jarvis doctor``: is Jarvis ready on this robot? Its nodes, the recovery mode, plans, rules, open faults, the data disk, the recorder, the clock and the gateway, each problem with its fix; exit code 1 on a problem, ``--json``.
